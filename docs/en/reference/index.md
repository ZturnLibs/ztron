# Reference

The reference section is a lookup companion: the [CLI Reference](/reference/cli) lists every subcommand and option of the `ztron` CLI; the [Command Surface Reference](/reference/commands) enumerates all runtime-registered `plugin:*|*` commands (generated from the manifest, mirroring the runtime registration surface one-to-one); the [Configuration Reference](/reference/config) covers every field of `ztron.conf.json` (generated by `gen:config`, do not edit by hand); and the [API Reference](/reference/api/) is the TypeDoc-generated API documentation for `@zturnlibs/ztron-api`, with the Chinese tree as a translation overlay.

| Page | Description |
| --- | --- |
| [CLI Reference](/reference/cli) | The seven main commands of the `ztron` CLI (init/dev/build/codegen/check/signer/version) plus utility commands |
| [Command Surface Reference](/reference/commands) | All `plugin:*|*` commands and their permission owners, generated from the manifest (`tests/helpers/manifest.ts`) |
| [Configuration Reference](/reference/config) | Every field of `ztron.conf.json`, generated by `pnpm --dir docs run gen:config` |
| [API Reference](/reference/api/) | TypeDoc-generated API docs for `@zturnlibs/ztron-api` · Chinese is a translation overlay |

适用版本：`ztron 0.3.1`

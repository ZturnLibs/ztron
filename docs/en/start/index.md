# Start

This section is the entry point for getting started with Ztron: first read the [Introduction](/start/intro) to learn what Ztron is — a Tauri-style desktop framework rewritten in TypeScript, running on txiki.js and the system WebView; then follow [Prerequisites & Installation](/start/install) to set up your macOS environment, clone the repo and build the native chain; use [Quick Start](/start/quick-start) to run the hello example within 10 minutes; and browse the three runnable examples shipped in the repo (hello / multiwin / menuprobe) under [Examples](/start/examples).

| Page | Description |
| --- | --- |
| [Introduction](/start/intro) | What Ztron is: architecture overview, use cases and current status, relation to Tauri |
| [Prerequisites & Installation](/start/install) | macOS/Node/pnpm prerequisites; clone the repo, install dependencies and build the native chain |
| [Quick Start](/start/quick-start) | Run the hello example in 10 minutes: dev, the `ztron check` regression and packaging the app |
| [Examples](/start/examples) | Three runnable examples under `examples/`: hello, multiwin, menuprobe |

适用版本：`ztron 0.3.1`

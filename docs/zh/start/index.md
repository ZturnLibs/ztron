# 开始

本节是 Ztron 的上手入口：先用[简介](/start/intro)了解 Ztron 是什么——一个以 TypeScript 重写、运行于 txiki.js 与系统 WebView 之上的 Tauri 风格桌面框架；再按[前置条件与安装](/start/install)准备 macOS 环境、获取源码并构建原生链；然后用[快速开始](/start/quick-start)在 10 分钟内跑通 hello 示例；最后通过[示例](/start/examples)浏览仓库自带的三个可运行示例（hello / multiwin / menuprobe）。

| 页面 | 说明 |
| --- | --- |
| [简介](/start/intro) | Ztron 是什么：架构一览、适用场景与现状、与 Tauri 的关系 |
| [前置条件与安装](/start/install) | macOS/Node/pnpm 等前置条件，获取源码、安装依赖并构建原生链 |
| [快速开始](/start/quick-start) | 10 分钟跑通 hello 示例：dev 运行、`ztron check` 回归与打包应用 |
| [示例](/start/examples) | `examples/` 下三个可运行示例：hello、multiwin、menuprobe |

适用版本：`ztron 0.3.1`
